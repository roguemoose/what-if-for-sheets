Excel's What-If Analysis, in Google Sheets

What-If for Sheets brings the four what-if tools Excel users miss most into one sidebar: Data Tables, Goal Seek, Scenario Manager and Monte Carlo simulation. Point it at your existing formulas; no rebuilding required.

Four tools

  • Data table: vary one or two inputs over a list of values and get a grid of results, like Excel's Data Table. Great for sensitivity tables (price vs volume, rate vs term).
  • Goal seek: find the input value that makes a result hit a target, for example the units needed to reach $10,000 profit.
  • Scenarios: save named sets of input values, switch between them, and build a side-by-side summary report.
  • Simulate: give uncertain inputs a normal, uniform or triangular distribution, run the model hundreds of times, and see the mean, percentiles and a histogram.

Every run puts your input cells back the way they were, and results are written to a new sheet so your model is never overwritten.

Get started

  1. Install What-If for Sheets from the Google Workspace Marketplace.
  2. Open Extensions → What-If for Sheets → Load example for a ready-made profit model with all four tools set up, or Open What-If to use your own sheet.
  3. Pick cells with Use selection. Value lists can be typed as 10, 20, 30, 10 to 50 step 10 or 0 to 1 in 5, or taken from a range.
Good to know. Most models run in the browser with the built-in fast engine: a 10,000-run simulation or a 100x100 data table takes about a second, and every fast result is checked against Google Sheets first. Models using functions the engine doesn't know yet fall back to recalculating in Sheets (about a second per run). Input cells must hold plain values, not formulas.
